Design system

Cake Lake Bakery — visual language

The tokens, type, and components used across the site. Reference this when building new pages so everything stays one consistent brand rather than a collection of one-off screens.

Color

Palette

Warm and fresh rather than the typical bakery "cream + terracotta" default — cream stays light, and the personality comes from raspberry, pistachio and honey doing distinct jobs rather than decoration.

Typography

Type scale

Fraunces carries the personality — used with restraint, on headlines only. Inter handles everything readable. JetBrains Mono marks anything transactional: prices, order numbers, codes, timestamps.

Signature element

The layered tracker

Not a generic 1-2-3-4 stepper.

Order status is shown as a cake literally being built layer by layer — placed → oven → decorating → ready. It's the one deliberately bold, illustrated moment in an otherwise restrained design, used only for order tracking so it stays meaningful rather than decorative.

Components

Buttons

Primary (honey) for the one action per screen that matters most. Ghost (outlined) for everything secondary. Never more than one primary button visible at a time in a section.
