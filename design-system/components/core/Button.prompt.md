One-line: the brand's only button — always pill-shaped, honey for the primary action and outlined ghost for the rest.

```jsx
<Button variant="primary">Order online →</Button>
<Button variant="ghost" size="sm">Track an order</Button>
```

Variants: `primary` (honey fill + honey glow shadow), `ghost` (ink outline, inverts to solid ink on hover), `inverse` (for use on the dark ink tracker block — outline goes honey on hover). Sizes `md` (14/26px) and `sm` (9/16px). Never show two primaries in one section.
