photography.** Real photography of the client's actual cakes should replace
every file here before anything ships to production — see "Brand assets" in
[`docs/requirements/requirements.md`](../requirements/requirements.md)
(still an open question). Each maps to a sample menu item in the prototype
(`prototype/`) and `design-system/ui_kits/cakelake-site/data.jsx`.
