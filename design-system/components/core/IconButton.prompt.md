One-line: round icon control — `add` is the ink "+" on product cards, `outline` is the paper header button (cart, account).

```jsx
<IconButton variant="add" aria-label="Add to cart">+</IconButton>
<IconButton variant="outline" badge={3}><img src="../../assets/icons/shopping-bag.svg" width="18" /></IconButton>
```

The `badge` count is always JetBrains Mono on berry.
