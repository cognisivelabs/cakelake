One-line: promotions only — the dashed coupon look signals "limited time", so never use it for evergreen content.

```jsx
<OfferCard tag="Ends Fri" title="20% off Eid boxes" description="Any celebration cake, 48h ahead." code="EID20" />
```

Lives in a horizontally scrolling 280px-wide strip. Set `punchColor` when the background isn't cream.
